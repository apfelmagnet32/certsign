What's being checked here

  1. The file is searched for the signature block at the end (algorithm, signature, certificate — all base64-encoded).
  2. The public key is read from the embedded certificate.
  3. The RSA-SHA256 signature is verified against the content before the signature block.
  4. If even one byte of the original content changes, step 3 fails.
